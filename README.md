# booksore-lab — CICADA, лабораторная работа № 2

Девять страниц книжного магазина по макетам из файла Figma: главная, каталог, шесть книг и оформление заказа. Работа выполнена в исходной папке проекта без сборщика.

## Как открыть

1. Откройте эту папку в VS Code: «Файл → Открыть папку».
2. Откройте `index.html` в браузере двойным щелчком в Проводнике. Установка Node.js и npm для сайта не нужна.
3. Либо нажмите правой кнопкой по `index.html` в VS Code и выберите Open with Live Server, если расширение уже установлено.
4. Подробный разбор находится в `ПОСТРОЧНОЕ-ОБЪЯСНЕНИЕ.html`; его текстовая версия — `ПОСТРОЧНОЕ-ОБЪЯСНЕНИЕ.md`.

## Соответствие заданию

- Главная, страница списка, страницы отдельных элементов, страница формы созданы.
- На всех страницах есть шапка, меню, подвал, логотип и favicon.
- Bootstrap используется для сетки, карточек, кнопок, формы, отступов и вспомогательных классов.
- Собственный файл CSS подключён после Bootstrap.
- Основные блоки HTML, CSS и JavaScript снабжены комментариями.
- Макет перенесён в настоящие HTML-элементы: ссылки и форма работают.
- Публикация GitHub Pages: состояние и адреса указаны в `ПУБЛИКАЦИЯ.md`.

## Как проверить вручную

1. На главной откройте каталог.
2. Найдите `Шен`, затем выберите «Ужасы»: подходящих книг не будет. Очистите поиск — появятся две книги ужасов.
3. Выберите «Все жанры», откройте любую карточку и нажмите «Оформить заказ».
4. Проверьте, что в форме выбрана та же книга. Измените количество и проверьте сумму.
5. Пустые обязательные поля, неверный email и короткий телефон не должны проходить проверку.
6. Для доставки введите адрес; для самовывоза поле скрыто и исключено из проверки.
7. После заполнения нажмите «Отправить заказ»: появится сообщение о локальной проверке.
8. Уменьшите ширину окна: карточки и колонки перестроятся.

Форма учебная: сервер, платежи и отправка сообщений не подключены. Личные данные не сохраняются в localStorage и не отправляются по сети. Если JavaScript отключён, кнопка заказа остаётся неактивной. В каталоге при этом видны все книги.

## Проверка

Все 9 страниц проверены в Edge при ширине 1440, 768, 390 и 320 px: изображения, относительные ссылки, уникальные id, основные блоки и отсутствие горизонтального переполнения. Отдельно проверены поиск, жанры, переходы из всех шести книг в заказ, сумма, ограничения количества, имя, email, телефон, адрес и работа без JavaScript. Ошибок в консоли не обнаружено.

## Особенности переноса макета

Сохранены названия книг, цены, исходные изображения, кремовый фон и фиолетовая палитра. Исправлены очевидные пропущенные пробелы и опечатки в текстах. В исходном макете шрифт Batang; CSS использует его при наличии на компьютере, иначе Georgia или Times New Roman. Фиксированные координаты Figma заменены потоком документа и сеткой Bootstrap, чтобы страницы работали на телефоне. К форме добавлены выбор книги, количество и условное поле адреса.
