В коммиты не следует добавлять `Co-authored-by` или другого соавтора.

## Если публиковать вручную

1. Откройте существующий публичный репозиторий https://github.com/moonlightovvl/booksore-lab.
2. В нём выберите **Add file → Upload files**.
3. Загрузите содержимое папки `2лаба`: HTML-файлы, папки `css`, `js`, `images` и пояснения. Саму внешнюю папку `2лаба` добавлять в качестве ещё одного уровня не нужно: `index.html` должен находиться в корне репозитория.
4. Проверьте, что папки загружены с содержимым. Выполните commit с сообщением `Complete CICADA laboratory work 2`. Соавторов не добавляйте.
5. Откройте **Settings → Pages**.
6. В **Build and deployment → Source** выберите **Deploy from a branch**.
7. Выберите ветку `main` и папку `/ (root)`, затем **Save**.
8. Дождитесь успешной публикации. GitHub покажет адрес сайта на странице Pages.
9. Откройте этот адрес. Проверьте каталог, любую книгу, форму и загрузку обложек.
10. Для сдачи укажите две реальные ссылки: репозиторий с исходниками и опубликованный сайт.

Файл `.nojekyll` уже добавлен. Он позволяет отдавать проект как обычные статические файлы. Все пути относительные: сайт рассчитан и на локальное открытие, и на размещение в подпапке репозитория GitHub Pages.

Ожидаемый адрес этого проекта: https://moonlightovvl.github.io/booksore-lab/. Пока успешное открытие сайта не проверено, эта запись не означает завершённую публикацию.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
